# Supply Chain Delivery Analysis

## Project Overview
This project focuses on analyzing supply chain operations, sales performance, and delivery risks using Power BI.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Business Objectives
- Analyze overall sales and profit performance.
- Identify high-performing product categories.
- Compare regional performance.
- Understand late delivery risks.
- Evaluate shipping mode performance.

## Dashboard Features
- KPI Cards
- Sales and Profit Analysis
- Regional Performance
- Category-wise Analysis
- Delivery Risk Analysis
- Interactive Filters and Slicers

## Key Learnings
- Data cleaning and transformation.
- Creating DAX measures.
- Building interactive dashboards.
- Presenting business insights through visualizations.

- Power BI Dashboard (.pbix)

## Conclusion
This project demonstrates the use of Power BI to analyze supply chain performance and communicate actionable business insights.
